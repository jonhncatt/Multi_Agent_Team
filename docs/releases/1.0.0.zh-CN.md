# Validation Assistant 1.0.0 发布说明

1.0.0 提升本地代码搜索速度与职责清晰度，并修复 Runtime 在授权或用户选择后继续执行时的界面状态闪变。

## Local Search

- 新增独立的 `search_files`，通过可复用的文件名 corpus 和自主实现的 fuzzy ranking 搜索模糊文件名或路径，不包含 Nucleo 源码。
- `search_codebase` 专注内容搜索：安装 ripgrep 时直接执行单次 `rg`，未安装时保留功能等价的 Python fallback。
- `glob_file_search` 继续用于精确 glob，文件名 fuzzy search、内容搜索和 glob 的职责不再重叠。
- 保留 structured result、ignore 规则、权限检查、取消、超时、进程树清理与不完整结果标记；同时减少运行数据对代码搜索的污染。
- 增加交错、预热后的新旧实现 benchmark，并覆盖 Windows / Python 3.11 可移植性、缓存新鲜度和搜索结果正确性。

## Runtime Resume 连续性

- `request_user_input`、命令授权和 task update 继续执行时，保留同一 logical turn 的 Plan、工具时间线、日志和累计工具数。
- 修复 resume bootstrap snapshot 与 pending assistant activity 用空值覆盖现有状态的问题，工具数不再从 1 重新开始。
- 用户选择回显包含问题标题，例如 `测试方向: A：代码结构分析`。

## 模型配置

- OpenAI-compatible Provider 的内置默认模型更新为 `gpt-5.6-luna`；环境变量显式配置仍保持更高优先级。

## 验证

- 完整本地测试：1061 passed，1 skipped。
- Python 编译检查和前端 JavaScript 语法检查通过。
