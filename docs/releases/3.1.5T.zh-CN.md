# Vintage Programmer 3.1.5T 发布说明

3.1.5T 是一次 Codex 风格 context 与长对话性能发布，重点把 context meter 从每轮阻塞式精算改成轻量状态、按需详情和可手动 compact，同时修复长对话里发送短消息仍可能等待很久的问题。

## 重点更新

- Context 状态轻量化：聊天主路径默认复用 cached/quick snapshot，不再每轮同步跑全量 tokenizer 精算。
- 新增本地命令：`/status` 直接打开 context/status 详情，不进入普通模型回答流程；`/compact` 直接触发上下文整理，并在 timeline 中显示 `contextCompaction`。
- 自动 compact 策略调整：默认 80% context window 后进入候选复核，95% 进入危险整理线；旧聊天和工具输出噪音超过软阈值时建议整理，但当前用户长输入和附件原文不会因为噪音阈值被 compact。
- 首页 Context UI 简化：默认展示一行 Codex 风格状态，点击后查看模型窗口、预计使用、剩余、估算模式、整理阈值和未触发原因。
- Agent 运行展示优化：执行牌更聚焦当前 agent 正在做什么，运行进度和 pending assistant 内容衔接更自然。
- Slash 菜单修复：输入 `/` 后支持菜单提示，`/status` 和 `/compact` 不再静默失败，方向键、回车和 Esc 选择流程可用。
- 长对话短输入加速：短消息不再为了计算当前用户输入预算而同步初始化 exact tokenizer，切换 thread 后再发送“你好”这类短消息应明显更快。
- Runtime 诊断增强：phase timings 新增 `runtime_model_context_ms`、`runtime_user_request_limit_ms`、`runtime_context_manager_normalize_ms`、`runtime_context_pack_ms`、`runtime_pre_model_ms` 等字段，方便定位模型请求前的本地耗时。
- 前端缓存更新：静态资源版本已同步到 `3.1.5T`，升级后会加载新的 JS/CSS。
