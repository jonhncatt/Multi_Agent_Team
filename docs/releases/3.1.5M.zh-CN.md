# Vintage Programmer 3.1.5M 发布说明

3.1.5M 是一次 thread 详情加载性能发布，重点是让打开历史聊天时只读 session 并尽快返回消息，把 default project/git、Docker、provider/model 可用性检查从详情加载路径中移除。

## 重点更新

- Thread detail 快速路径：`/api/thread/{id}` 和 full turn 详情改为只读 session JSON，不触发 legacy migration、default project 补齐或写回磁盘。
- 去掉无关预检：详情加载不再同步检查 default project/git、Docker 或 provider/model 可用性；provider/model 是否可用改为发送消息时验证。
- Runtime status 精简：Docker 状态检查暂时禁用，provider 列表不再提前做 auth summary 预检。
- 前端加载反馈：点击 thread 后立即显示小圆圈；如果已有缓存消息，会保留旧消息并在顶部显示刷新状态。
- 状态兼容：权限状态和上下文估算继续保留接口字段，但优先使用后台或已缓存状态，不阻塞消息显示。
