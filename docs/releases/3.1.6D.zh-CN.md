# Vintage Programmer 3.1.6D 发布说明

3.1.6D 为 GPT-6 Astra 补齐推理强度支持。

## GPT-6 Astra 推理强度

- 选择 `gpt-6-astra` 后，推理强度面板正常解锁，不再显示 `Locked`。
- 前端、运行时和模型后端统一识别 GPT-6 Astra，显式推理强度会正确传递到模型 API。
- 支持 `company/gpt-6-astra` 等带服务商前缀的模型名，同时继续锁定不支持推理强度的模型。
- Priority 快速模式和推理强度面板对 GPT-6 Astra 的能力判断保持一致。
