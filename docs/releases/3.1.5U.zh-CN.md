# Vintage Programmer 3.1.5U 发布说明

3.1.5U 是一次 Agent 运行状态与回答收束体验修复发布，重点解决“答案已经显示，但上方执行面板仍停留数秒才收束”的问题，尤其面向 Windows 机器上更明显的视觉拖尾。

## 重点更新

- 回答正文出现即收束：当 `run_finished` 或 `turn_completed` 已经带回可显示答案时，pending assistant 会立即转成普通 assistant 消息，并收起 live UI。
- 不再等待 final payload 才视觉完成：后续 final payload 仍会补齐正式元数据，但不会继续占住上方运行面板。
- 活动预览隐藏更积极：只要 assistant 正文已经可见，执行牌里的活动预览会立即隐藏，避免“结果已准备完成”“回答完成”在答案上方停留。
- 模型等待状态更清楚：发送请求后 pending assistant 文案统一为更短的“Agent 已发送请求，正在等待回应: <model>”，减少“正在理解问题”和模型等待之间的错位感。
- Thread 批量选择增强：侧边栏支持先点一个 thread，再按住 Shift 点击另一个 thread，批量选中范围内的 thread，并用于批量删除。
- 运行状态文案整理：减少重复、过长和容易误解的状态描述，让首页 Agent 展示牌和 pending assistant 更一致。
- 前端缓存更新：静态资源版本已同步到 `3.1.5U`，升级后会加载新的 JS/CSS。
