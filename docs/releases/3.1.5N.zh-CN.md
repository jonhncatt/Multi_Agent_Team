# Vintage Programmer 3.1.5N 发布说明

3.1.5N 是一次 thread 详情加载稳定性发布，重点修复新建 thread 发送消息后快速切换到其他 thread、再切回原 thread 时聊天区可能变空的问题。

## 重点更新

- 运行中 thread 快照保护：前端现在能识别某个 thread 缓存里是否还有 live run，避免切换时用空页面状态覆盖正在运行的消息。
- 发送瞬间同步缓存：点击发送后会立即把用户消息和 pending assistant 消息写入 owner thread 的缓存，不再只依赖 React 异步渲染后的消息列表。
- 详情刷新不覆盖 live 消息：thread detail 返回时，如果本地已有 live snapshot，会保留运行中的消息、active turn 和 runtime state，避免暂时为空的后端详情把聊天区清空。
- 快速切换更稳：新建 thread、发送消息、马上切到其他 thread、再切回原 thread 时，会继续显示用户消息和运行中状态；最终响应回来后正常替换 pending assistant 消息。
- 保留 3.1.5M 的详情加载加速：历史聊天详情仍然只走 session 读取路径，不同步检查 default project/git、Docker 或 provider/model 可用性。
