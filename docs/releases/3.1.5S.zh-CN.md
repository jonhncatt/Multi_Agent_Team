# Vintage Programmer 3.1.5S 发布说明

3.1.5S 是一次 Windows 启动体感和聊天界面体验发布，重点减少新 thread 首次进入时的等待，修正运行结束后的草稿/整理状态拖尾，并补齐消息复制、运行中输入和主题色选择。

## 重点更新

- 新 thread 启动更快：优化 project resolve、session seed、session load 和 session ready 的前端启动路径，降低 Windows 本机进入新 thread 时的首屏等待。
- 避免 thread 创建后的额外 reload：新 thread ready 事件不再触发不必要的重新加载，减少刚开始页面停留很久的体感。
- 耗时显示更贴近实际：聊天耗时统计改为覆盖从提交到答案 ready 的端到端时间，避免只显示 runtime 执行段导致低估总等待。
- 结果收束更干净：最终答案已完成后会清理 streaming draft，减少答案重复显示和“正在整理结果”长时间残留。
- 运行中输入框保持可编辑：模型运行时仍然可以继续输入下一条内容，只保持发送按钮不可点击。
- 消息复制按钮：聊天消息下方新增悬停显示的复制按钮，图标已按截图缩小，并修正前后方块的遮挡关系。
- Settings 新增主题色：可在石墨、蓝色、绿色、紫色、玫红之间选择，主题色会同步影响 VP logo、新线程按钮和发送按钮，并持久化保存在本地。
- 浏览器运行时增强：支持使用本机 Chrome profile 的浏览器模式，便于企业环境复用登录态，并补充对应回归测试。
- 前端缓存更新：静态资源版本已同步到 `3.1.5S`，升级后会加载新的 JS/CSS。
