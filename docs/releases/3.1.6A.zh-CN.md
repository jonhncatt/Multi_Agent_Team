# Vintage Programmer 3.1.6A 发布说明

3.1.6A 汇总了 3.1.5Z 之后的 Windows 桌面更新体验、多 Thread 操作和运行记录可靠性改进。这个版本重点解决更新完成后的重启、连续审批、文件改动摘要以及 Subagent 结果在切换 Thread 后的可见性问题。

## Windows 桌面更新与重启

- 更新成功后显示明确的完成对话框，提供“关闭”和“重启 VP”两个选择。
- 选择重启后，由桌面启动器启动新的 VP 进程并关闭旧实例，让新版本代码立即生效。
- 重启过程重新进入 Preparing 启动阶段，减少只刷新页面但后台仍运行旧代码的误判。
- 优化 Windows 重启流程，避免向用户暴露临时 PowerShell 窗口，并改善旧进程退出和新进程接管的时序。

## Thread 与并发体验

- 默认可同时运行的 Thread 数量从 3 提升到 5，并保留环境变量覆盖能力。
- Thread 支持置顶和取消置顶；置顶状态写入持久化元数据，刷新或重启后仍然保留。
- 修复同一轮存在多个连续审批时，提交第一个审批后第二个按钮可能暂时失效的问题。
- 调整长命令轮询契约，使 Runtime 能稳定继续等待后台命令，而不会因为轮询参数或模型调用方式不一致而提前失去执行状态。

## 文件修改与 Subagent 记录

- 文件修改摘要随 Thread 活动详情持久化；切换到其他 Thread 再返回后，已修改文件仍然可见。
- 兼容旧的活动记录：旧数据缺少新字段时，不会在重新加载过程中覆盖已经获得的文件修改摘要。
- 修复 Subagent 已完成但切换 Thread 后展开内容为空的问题；角色、任务、摘要和工具数量现在会在前端标准化过程中保留。
- 保持后台 Subagent 的完成状态和作业内容一致，避免只看到“已完成”通知却无法查看实际结论。
