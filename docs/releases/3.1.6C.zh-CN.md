# Vintage Programmer 3.1.6C 发布说明

3.1.6C 改进代码搜索的可中断性、Subagent 状态恢复和 Thread 模型隔离。

## 代码搜索

- 搜索在独立受控进程执行；点击停止可以中断搜索，包括没有安装 ripgrep 时的 Python 回退搜索。
- 整次搜索设置 20 秒时限，超时返回已找到的部分结果并明确提示未搜索完整。
- 默认跳过常见依赖和缓存目录，在 Git 工作区遵循忽略规则；限制大文件读取和结果数量。
- Windows 搜索启动 Git、rg 时保持后台运行，不额外弹出控制台。

## Subagent 状态与压缩

- Future 已结束但未正确保存结果时，补写完成、取消或异常状态，避免继续等待已结束任务。
- VP 重启后，上一次后台遗留的活动任务明确标记为重启中断；已保存的完成结果仍可读取。
- 每次主模型请求前，从 Thread 的任务记录重建 Subagent ID、任务、状态和结果可用性，不依赖压缩摘要保留原始 spawn 消息。
- 停止父任务等待时能及时退出等待，不把仍在执行的旧 Subagent 误标为完成。

## Thread 模型与回答链接

- 模型、服务商、推理强度和 Priority 设置按 Thread 独立保存在当前浏览器，刷新后恢复。
- 新 Thread 继承创建时的选择，之后独立调整；后台排队或恢复请求使用所属 Thread 的模型设置。
- 回答中的非页内锚点链接在新页面打开，保留 VP 页面，并继续进行 HTML 安全过滤。
