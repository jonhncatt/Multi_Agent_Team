# Vintage Programmer 3.1.5X 发布说明

3.1.5X 汇总了 3.1.5W 之后的一轮核心架构与可靠性改造，重点是让 Agent 以 Thread 保存真实对话，由 Runtime 管理边界，并用工具结果和权威验证推动任务完成。

## 重点更新

- Session 与 Thread 对齐：模型主要接收 typed transcript，不再每轮重复旧 Harness 六要素。
- Thread 保存可继续历史，Turn Trace 保存工具校验、耗时、错误和恢复；旧 Runs 只读兼容。
- 建立真实任务 Eval 和工具失败恢复基线，覆盖 C/C++、多文件分析、Markdown、Skill 维护、追加指令和 Subagent。
- Skills 收敛为全局 Built-in 与 Team 两层；Builtin 只读，Team 随 VP Git 仓库共享。
- 支持模型按需创建单层只读 Subagent，并并行处理探索、测试、日志和总结任务。
- Agent 运行期间可以追加指令，在安全模型边界合流到当前 Turn。
- Plan、实时状态、等待、耗时和最近进展同时展示，修复消息和执行面板顺序问题。
- Git 外部写入使用精确的一次性审批；`exec_command` 显示模型填写的执行目的。
- 公司 OpenAI-compatible Chat Completions 探针支持自定义 Base URL、CA、Streaming 和 Tool Calling 检测。

## 兼容性与验证

- 保持旧 Session、现有 API、前端调用和公司 Chat Completions 接口兼容。
- 旧 Session 首次读取时自动迁移并保留备份，不需要手动脚本。
- 发布提交通过全量测试：`680 passed`。
