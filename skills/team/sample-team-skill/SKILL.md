# Sample Team Skill

This disabled example shows the strict format for a Team Skill shared through the Vintage Programmer repository.

## Workflow

- Replace the name with a short lowercase action-oriented name.
- Make the description identify the exact future task that should trigger the skill.
- Put only reusable team guidance in this body.
- Do not include credentials, personal absolute paths, temporary task data, or project-local assumptions.
- Enable the skill only after its workflow and validation expectations have been reviewed.
