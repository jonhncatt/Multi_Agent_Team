# Sample Workspace Skill

This disabled skill is a user-editable example under `workspace/skills`.

## Workflow

- Replace the `name` with a short lowercase skill name.
- Replace the `description` with the exact task pattern that should trigger the skill.
- Put only reusable guidance in this body.
- Enable the skill when it is ready to appear in the available skills list.
